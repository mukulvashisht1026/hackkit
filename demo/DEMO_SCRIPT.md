# 2-minute demo script (fill in on the day)
1. **Hook (10s)** – one sentence: who suffers today, with a number if you have one.
2. **Problem (15s)** – the manual workflow the brief describes, in their words.
3. **Live demo (75s)** – one real input → insight → recommended action. Use the seeded dataset as fallback. Show the *evidence* behind one AI answer.
4. **Why it works (15s)** – the one non-obvious idea (e.g. drift detection, thesis-fit + gap analysis).
5. **Next steps (5s)** – what you'd build with another week.

Checklist: demo works offline? backup screen recording? one person drives, one talks? judging criteria mapped to slides?
